# Standalone NCS development decoder
Public source-only tool. Uses the MIT-declared oozextract Rust library at https://github.com/lvlvllvlvllvlvl/oozextract/commit/8acaeb2bc375dd56c413a83aae4e87156136fdac. See upstream Cargo.toml and upstream source for attribution and licensing. Retain dependency notices and generated lockfile. The interface is raw Oodle block bytes on stdin and exact-size decompressed bytes on stdout. This utility does not parse PAK/NCS headers, load the game, modify saves, or include any private mod asset. Build/test separately from BL4 Custom. Do not put Caites' PAK or decoded private assets into this public repository. Generated binary is for offline development only.
